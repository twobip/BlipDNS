        DomainTypeValueTTL

        Static DNS records answered locally by blipd before forwarding to upstream. A/AAAA records return IP addresses; CNAME records return a canonical name alias. A domain prefixed with *.  (e.g. *.lan.twobip.com) is a wildcard that matches any subdomain but not the apex itself. Records are fleet-wide and pushed to every instance (use per-instance overrides in Settings for instance-specific values).

        Query Log

        Older entries are pruned automatically every hour. Applies to the query log and the upstream-errors details. Longer retention uses more disk: roughly 30 MB per day at typical home traffic, so a month is around 1 GB. Does not affect dashboard statistics or blocklists.
